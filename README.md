### 🍺 Gerade am Zapfhahn: [Zum Goldenen Merge](https://github.com/Taeubel/zum-goldenen-merge)

Ein Wirtshaus-Deckbauspiel aus Österreich, das wie Open-Source-Software entsteht. Jede Karte ist eine YAML-Datei, neue Karten kommen per Pull Request, und ein Bot spielt jede Einreichung 2.000-mal durch und postet einen Balance-Bericht in den PR. Wer mitmacht, steht mit Namen auf der gedruckten Karte.

**Mitmachen geht auch ohne Programmierkenntnisse:**

* 🃏 [Kartenidee einreichen](https://github.com/Taeubel/zum-goldenen-merge/issues/new?template=1-karte.yml)
* 🌱 [Einstiegsaufgaben („good first issue“)](https://github.com/Taeubel/zum-goldenen-merge/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22): Speckknödel für Tirol, die Bregenzer Seebühne, das Golser Martiniloben …
* 🎲 [Print-and-Play ausdrucken und Spieltest-Bericht schreiben](https://github.com/Taeubel/zum-goldenen-merge#spielen)
* 🖼️ [Alle Karten in der Galerie ansehen](https://taeubel.github.io/zum-goldenen-merge/)
